# Климатическая камера Wiren Board — скрипты правил wb-rules

Два JavaScript-скрипта для движка правил **wb-rules** (встраивается в прошивку
Wiren Board 8). Никаких npm-зависимостей и отдельных сервисов не требуется:
файлы копируются в репозиторий правил `/etc/wb-rules/`, дальше wb-rules
подхватывает и перезагружает их автоматически.

| Файл | Роль |
|---|---|
| `climate_ui.js` | Виртуальное устройство `climate_ui`: органы управления + readonly-выход термостата + индикация температур |
| `climate_ctrl.js` | Термостат: принимает параметры, читает датчики RS-485, управляет реле компрессора |

## Состав системы

- **WB-WRM2** (адрес 134) — реле K1 управляет компрессором, MQTT-топик
  `wb-mrwm2_134/K1`; имеет встроенный внешний датчик температуры.
- **WB-MAI6** (адрес 28) — измеритель температур, топики (с пробелами!):
  - `wb-mai6_28/IN 1 N Temperature` — термометр внутри камеры, низ
  - `wb-mai6_28/IN 2 P Temperature` — термометр внутри камеры, верх
  - `wb-mai6_28/IN 1 P Temperature` — переносной термометр внутри камеры
  - `wb-mai6_28/Internal Temperature` — температура снаружи камеры
- Оба модуля на одной шине **RS-485**, подключены к **Wiren Board 8**
  (опрос через `wb-mqtt-serial`).

## Каналы виртуального устройства `climate_ui`

| Канал | Тип | Доступ | Описание |
|---|---|---|---|
| `Mode` | switch | RW | 0 = OFF, 1 = AUTO |
| `Manual` | switch | RW | 0 = OFF, 1 = ON (ручной режим в AUTO) |
| `TargetTemp` | value | RW | уставка температуры, °C (по умолч. 5.0) |
| `Hysteresis` | value | RW | гистерезис уставки, °C (по умолч. 0.5) |
| `CompressorCommand` | switch | **RO** | выход термостата (0/1) |
| `CompressorActual` | switch | RO | фактическое состояние реле `wb-mrwm2_134/K1` |
| `TempBottom` / `TempTop` / `TempPortable` / `TempExternal` | value | RO | температуры с датчиков |

## Логика термостата (`climate_ctrl.js`)

Приоритеты:

1. `Mode = OFF` → команда 0 (компрессор обесточен).
2. `Mode = AUTO` и `Manual = ON` → команда 1 (принудительная работа).
3. `Mode = AUTO` и `Manual = OFF` → автоматика:
   - измеряемая температура `T = среднее(низ, верх)`;
     если оба основных датчика недоступны — переносной термометр;
   - включение компрессора при `T > TargetTemp + Hysteresis`;
   - выключение при `T < TargetTemp − Hysteresis`;
   - в зоне гистерезиса состояние не меняется.
4. Защита компрессора: минимальный цикл работы `MIN_ON_SEC` и простой
   `MIN_OFF_SEC` (по умолчанию 180 с; переопределяются переменными окружения
   сервиса wb-rules: `CLIMATE_MIN_ON_SEC`, `CLIMATE_MIN_OFF_SEC`).
5. Авария: все внутренние датчики молчат дольше `CLIMATE_STALE_SEC`
   (по умолч. 60 с) → команда принудительно 0, ошибка в лог.
6. При каждом перезапуске правил — безопасная позиция: команда 0.

## Схема взаимодействия скриптов

```
                Пользователь (веб-интерфейс WB / MQTT-команды)
                   devices/climate_ui/controls/<Param>/set
                                    │
                    ┌───────────────▼────────────────┐
                    │      climate_ui.js (wb-rules)  │
                    │  вирт. устройство "climate_ui" │
                    │  Mode, Manual, TargetTemp,     │
                    │  Hysteresis (RW)               │
                    │  CompressorCommand (RO)        │
                    └───┬────────────────────▲───────┘
   publish              │                    │  whenChanged
   wb/climate/set/*     │                    │  wb/climate/fb/…
   (retained)           │                    │
                    ┌───▼────────────────────┴───────┐
                    │     climate_ctrl.js (wb-rules) │
                    │  термостат + защита компрессора│
                    └───┬────────────────────▲───────┘
   publish              │                    │
   wb-mrwm2_134/K1 ─────┤                    │ wb-mai6_28/IN … Temperature,
   (команда реле)       │                    │ wb-mai6_28/Internal Temperature
                        │                    │
                 ┌──────▼──────┐      ┌──────┴──────┐
    RS-485 ══════│   WB-WRM2   │      │   WB-MAI6   │══════ RS-485
   (шина WB8)    │  K1→компрес-│      │ 4 датчика   │  (шина WB8)
                 │  сор        │      │ температуры │
                 └─────────────┘      └─────────────┘
```

Оба скрипта работают в одном процессе wb-rules и общаются через локальный
MQTT-брокер контроллера (`localhost:1883`), используя функции API
`publish()` / правила с `when:` по топикам. Температуры читаются напрямую
из каналов устройств wb-mqtt-serial через `whenChanged`.

## Быстрая проверка после установки

```sh
# значения параметров уходят из UI в термостат:
mosquitto_sub -t 'wb/climate/set/#' -v

# выход термостата и команда реле:
mosquitto_sub -t 'wb/climate/fb/#' -v -t 'wb-mrwm2_134/K1' -v

# смоделировать температуру выше уставки (проверка цикла термостата):
mosquitto_pub -r -t 'wb-mai6_28/IN 1 N Temperature' -x 12
mosquitto_pub -r -t 'wb-mai6_28/IN 2 P Temperature' -x 12
# через ~3 мин (MIN_OFF_SEC) при Mode=AUTO, Manual=OFF должна появиться
# команда 1 в wb-mrwm2_134/K1 и wb/climate/fb/CompressorCommand
```

Подробная пошаговая установка — в [INSTALL.md](INSTALL.md).
